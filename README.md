# FlowBoard

## O que é?
FlowBoard é um sistema que conecta planejamento de tarefas, especificações para desenvolvimento assistido por IA, execução, revisão no GitHub e métricas de fluxo. Seu diferencial é oferecer visibilidade contextual sobre colaboração humano–IA e qualidade das entregas sem classificar pessoas por volume de código ou obrigar declarações de uso de IA.
Proposta de valor: “Planeje melhor. Desenvolva com IA. Entregue com confiança.”
