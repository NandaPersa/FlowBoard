# FlowBoard backend
O back-end do FlowBoard será desenvolvido com java e springboot usando arquitetura hexagonal e monolito modular.
Implantação única da API, separação por domínio, sem microserviços no MVP.


## Tecnologias
- Java 21 LTS;
- Spring Boot 4.1.x;
- Maven;
- Spring Security;
- JWT access/refresh;
- BCrypt;
- PostgreSQL;
- Hibernate/JPA; 
- Flyway;
- OpenAPI 3; 
- springdoc;
